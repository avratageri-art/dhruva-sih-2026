### Security

- Environment-driven Compose credentials.
- Localhost-scoped default CORS origins.
- Public-target validation for infrastructure scans and bounded Tor responses.
- New collection seeds default to disabled pending explicit authorization.
- Removed an ignored backend environment file that contained a non-placeholder local Neo4j credential; rotation is required.
- Ignore rules for secrets, local databases, collection output, Tor state, and build artifacts.
